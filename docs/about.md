## 我怎样做项目

1. 先定义问题、数据划分和可以被反驳的实验假设。
2. 用最小实现验证数据流和张量形状。
3. 记录失败、限制和环境差异，不用不可靠指标包装结果。
4. 用 README、测试和复现说明把工作交给下一位读者。
